# デモデータセット説明

## 📊 データセット: sales_2023.csv

2023年の月次売上データ（架空）

### カラム説明
- `date`: 日付（月次）
- `product`: 商品名（ProductA, ProductB, ProductC）
- `sales`: 売上金額（円）
- `quantity`: 販売数量
- `region`: 地域（Tokyo, Osaka, Nagoya）
- `customer_type`: 顧客タイプ（new: 新規, existing: 既存）

### データの特徴
- **3月**: ProductAの売上が大幅減少（メルマガキャンペーン中止の影響）
- **6月**: ProductAの売上が急増（インフルエンサーマーケティングの効果）
- **9月**: 全商品で売上減少（台風による配送遅延）
- **11月-12月**: 年末商戦で過去最高売上

## 🎯 分析例

### 質問1: "3月の売上が減少した原因は？"

**データ分析**:
- 3月のProductA売上: 800,000円（前月比-33%）

**文書検索**:
- marketing_campaigns_2023.md: "3月にメルマガキャンペーン中止"

**統合回答**:
"3月の売上減少の主な原因は、メルマガキャンペーンの中止により新規顧客獲得が停止したためです。"

### 質問2: "6月の売上が急増した理由は？"

**データ分析**:
- 6月のProductA売上: 1,300,000円（前月比+44%）

**文書検索**:
- marketing_campaigns_2023.md: "6月にインフルエンサーマーケティング開始"
- customer_feedback_2023.md: "インフルエンサーの投稿を見て購入"

**統合回答**:
"6月の売上急増の主な理由は、インフルエンサーマーケティングの開始により認知度が大幅に向上したためです。"

### 質問3: "9月の売上減少の原因は？"

**データ分析**:
- 9月の全商品売上が減少（-21%）

**文書検索**:
- marketing_campaigns_2023.md: "9月中旬に台風が直撃、配送が1週間遅延"
- customer_feedback_2023.md: "9月の台風による配送遅延に多数のクレーム"

**統合回答**:
"9月の売上減少の原因は、台風による配送遅延（1週間）です。顧客からのクレームも多数発生しました。"
